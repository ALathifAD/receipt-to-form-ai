# 🧾 Receipt-to-Form Auto-Fill AI

An intelligent web application that automates data entry from shopping receipts using Generative AI.

## 🚀 Overview
This project is built for the **TP Malaysia AI Intern Assessment**. It allows users to upload a receipt image, extracts key information using Google's Gemini AI, and automatically populates an editable form for verification.

## 🛠️ Tech Stack
- **Framework:** Next.js 14+ (App Router)
- **AI Model:** Google Gemini 1.5 Flash
- **Styling:** Tailwind CSS
- **State Management:** React Hooks & Local Storage
- **Deployment:** Vercel

## ✨ Key Features
- **OCR & Extraction:** Automatically detects Merchant Name, Date, Amount, and Currency.
- **Editable UI:** Users can manually correct AI-generated data.
- **Fast Processing:** Leveraging Gemini 1.5 Flash for near-instant results.
- **Zero Database Setup:** Uses local storage for efficient, lightweight testing.
